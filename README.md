# SmartShorts 🎬

SmartShorts is a **mobile-first reels web app** designed for night-time viewing.

## ✨ Features
- Vertical full-screen reels
- Upload single or multiple videos
- Loop mode (hands-free viewing)
- Sleep timer (auto-stop playback)
- No likes, comments, or distractions

## 📱 Designed For
- iPhone browsers
- Late-night, low-distraction usage

## 🛠 Tech Stack
- React
- Mobile-first CSS
- HTML5 Video API

## 🚀 Run Locally
```bash
npm install
npm start
